# Proof2Impact 🌍

> Fund outcomes. Verify results. Create measurable impact.

Proof2Impact is a mobile-first impact platform designed to connect real-world problems with measurable outcomes.

## Core protocol

Problem
→ Mission
→ Funding
→ Milestone
→ Evidence
→ Verification
→ Settlement
→ Impact Passport

## Technology

- Android
- Kotlin
- Jetpack Compose
- Node.js
- TypeScript
- PostgreSQL
- Solidity
- Arc
- USDC
- Circle developer infrastructure

## Current status

🚧 Early development — Arc Testnet

The project is initially being developed on an Android device and will use GitHub for source control and Vercel for appropriate web/API deployment components.
