# Proof2Impact

## Mission

Proof2Impact is a mobile-first impact platform designed to connect real-world problems with measurable, verifiable outcomes.

## Core flow

Problem
→ Mission
→ Funding
→ Milestone
→ Evidence
→ Verification
→ Settlement
→ Impact Passport

## Initial blockchain

Arc Testnet

## Initial settlement asset

USDC

## Initial application

Android

## Development principle

Build the smallest verifiable end-to-end system first.

## Security principle

Never place production secrets, private keys, seed phrases, API secrets, or personal data in the Android application or Git repository.

## V1 scope

1. Mission creation
2. Mission discovery
3. Mission funding
4. Milestone tracking
5. Evidence submission
6. Verification
7. Testnet settlement
8. Impact Passport
