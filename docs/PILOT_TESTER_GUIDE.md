# Pilot Tester Guide

## Before testing
Use a supported Android device and synthetic/non-sensitive evidence. Record device model, Android version and app build.

## Test mission flow
1. Open the app.
2. Create a mission draft.
3. Add a milestone.
4. Capture a photo or select media.
5. Confirm the evidence fingerprint appears.
6. Prepare a review.
7. Schedule sync.
8. Repeat the same flow offline.

## Permission tests
Deny camera, microphone and location individually. Confirm the app remains usable and clearly explains what feature is unavailable.

## What to report
- Crash or freeze
- Wrong screen/state
- Lost evidence
- Incorrect hash
- Permission behavior
- Unexpected network use
- Battery or storage problem
- Accessibility issue

Never attach private identity documents or beneficiary records to a public issue.
