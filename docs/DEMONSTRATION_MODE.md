# Demonstration Mode

## Purpose
Demonstration Mode communicates the future Proof2Impact value proposition without pretending that prototype data is production-verified.

## Demo mission
**Wabukhonyi Community Water Access Pilot**

Outcome: improve reliable access to clean water for a fictional rural community.

### Milestones
1. Baseline mapping
2. Borehole rehabilitation
3. Water-quality test
4. Community handover

### Demo evidence
- Baseline site photograph
- Fictional inspection checklist
- Fictional water-quality report
- Fictional beneficiary count
- Fictional milestone completion record

Every item is labelled `DEMO DATA` and carries a synthetic ID.

## Demo lifecycle
`Evidence Captured → Integrity Fingerprint → Review Prepared → Verification Demonstration → Impact Record`

The demonstration must never label synthetic evidence as independently verified or funded.

## Demo dashboard
- Mission progress
- Milestone completion
- Evidence count
- Review status
- Impact readiness
- Trust timeline

## Future report
The eventual Impact Passport will assemble verified claims, evidence provenance, verification decisions and settlement records into a portable impact record. The pilot only demonstrates the information architecture.
