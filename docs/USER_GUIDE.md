# Proof2Impact Pilot User Guide

## What this pilot demonstrates
Proof2Impact helps teams organize missions, milestones and evidence for a future trusted verification and impact record.

## Quick demonstration
1. Open Proof2Impact Pilot.
2. Create a local mission draft.
3. Add a milestone draft.
4. Capture or select evidence.
5. Confirm the evidence appears with its SHA-256 fingerprint.
6. Prepare a verification review.
7. Test the biometric gate if supported.
8. Schedule the sync boundary.

## Important limitation
This build stores evidence locally. It does not prove that a remote verifier accepted the evidence, and it does not provide funding or settlement.

## Safe pilot use
Use synthetic projects, public-domain photographs or non-sensitive test material. Do not enter passwords, identity documents, financial records or private beneficiary information into the demonstration build.
