# Bug Reporting Guide

## Required information
- Build/version
- Git commit SHA if known
- Device model
- Android version
- Network state: offline / Wi-Fi / mobile data
- Reproduction steps
- Expected result
- Actual result
- Frequency
- Safe screenshot or screen recording

## Severity
- **P0:** security, data loss, unsafe release or catastrophic failure
- **P1:** major pilot workflow blocked
- **P2:** important defect with workaround
- **P3:** cosmetic or low-impact issue

## Privacy
Redact names, phone numbers, identity numbers, financial information, precise beneficiary locations and private media before submitting a report.
